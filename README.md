# mysoc-assets

Repositorio público de recursos gráficos MYSOC (logos e íconos) para uso en
correos automatizados e informes.

- `logos/`     — logos corporativos (MYSOC, variantes blanco/azul)
- `clientes/`  — logos de clientes MYSOC
- `icons/`      — íconos sueltos (correo, WhatsApp, alertas)
- `icons/apps/` — íconos de aplicaciones y servicios (PNG 160x160 transparente;
  manifiesto en `icons/apps/icons.json`, SVG fuente en `icons/apps/svg-source/`)
- `URLS.md`    — índice autogenerado de URL públicas

**Uso en correos:** referenciar siempre por `https://assets.mysoc.cl/<ruta>`
(nunca `raw.githubusercontent.com`, que no sirve `Content-Type` ni cache de CDN).
Ejemplo: `https://assets.mysoc.cl/icons/apps/google-drive.png`

**Dominio público:** https://assets.mysoc.cl
**Fallback (GitHub raw):** https://raw.githubusercontent.com/soportemysoc/mysoc-assets/main/

> Solo contenido público. No subir documentos ni datos sensibles.
